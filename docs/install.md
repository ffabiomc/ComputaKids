# Instalação inicial (experimental)
PHP 8.3, PDO MySQL, mbstring, MySQL 8 e HTTPS. Configure a raiz pública do domínio para public/; nunca exponha app/, config/ ou database/. Crie um banco vazio exclusivo e usuário com permissões de criação de tabelas. Crie config/install.key com segredo aleatório de pelo menos 32 caracteres, fora da raiz pública, com permissões restritas. Exemplo via terminal: openssl rand -hex 32 > config/install.key. O PHP precisa escrever em config/. Abra /install.php e informe o segredo, credenciais e administrador. Após sucesso, o instalador bloqueia novas instalações. Se a migração falhar parcialmente, não reutilize o banco sem revisão: DDL MySQL não é transacional. Não use dados reais; autenticação ainda não implementada. Validação em HostGator pendente.
